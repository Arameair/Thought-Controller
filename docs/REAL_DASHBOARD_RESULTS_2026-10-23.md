## Owner checklist

1. Play **Arameair/Thought** `experiment/spark-trace-thought-v1-20261023`.
2. Play **Arameair/Thought-Controller** `experiment/real-thought-dashboard-20261023`. If it says NOT REACHABLE, press **Find on this computer** → **Use**.
3. Open the engine's page in another tab: **Enable Thought (TEST)** for TASS, **Send one weak event**, **Send Goldshire visit** ×3.
4. Watch the dashboard (TASS): the Thought, its Traces and the Sparks appear on their own.
5. Open the Thought → **Evidence** and **Development history** → **Sleep**. Check the engine's page shows it sleeping.
6. On the engine, send one more Goldshire visit → the dashboard shows the same Thought active with 4 clues.
7. Click **Example Workshop** → not enabled, no thoughts.
8. Disable TASS on the engine, try **Resolve** in the dashboard → refused with the engine's reason. Enable TASS again.
9. Stop the engine → NOT REACHABLE. Play it → **Check again** → same Thought.
10. Stop/Play the dashboard → it reconnects by itself. **System Services** → **Copy Diagnostics**, paste with PASS/FAIL per step.

## Known gaps (next foundations to build)

1. **Identity integration.** Identity's wizard still speaks the old simulated protocol and pins the old dashboard commit, so it will show this build as INCOMPATIBLE. Next step: a real, authenticated Identity ↔ Thought ↔ Thought Controller registration and grant flow.
2. **Authentication.** Neither the engine nor the dashboard authenticates callers yet; separation is enforced per identity by the engine, not by identity of the caller.
3. **Real event sources.** The engine's events still come from its own buttons; nothing real feeds it yet (game screen, Discord, etc.).
4. Dashboard traffic counters reset on restart; the engine's metrics persist.
